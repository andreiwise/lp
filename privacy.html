Политика конфиденциальности

Последнее обновление: май 2025 года

Настоящая Политика конфиденциальности описывает, какие данные собираются при посещении сайта andreiwise.github.io/lp, как они используются и какие права есть у пользователя.

Этот сайт не собирает персональные данные автоматически и не использует сторонние трекеры или аналитику. Единственное действие, при котором вы передаёте данные — это переход в Telegram по вашей инициативе.

1. Какие данные собираются

Тип данных Что именно Как собирается
Технические данные IP-адрес, тип браузера, операционная система, страна Автоматически сервером GitHub Pages при загрузке страницы
Данные о посещении Страницы просмотра, время на сайте, источник перехода GitHub Pages логи (стандартные серверные логи)
Данные Telegram Username, имя профиля в Telegram Только если вы нажали кнопку и перешли в чат-бот
Персональные данные Не собираются На сайте нет форм, регистрации или ввода данных

2. Для чего используются данные

  • Технические данные используются исключительно для обеспечения работы сайта
  • Данные Telegram (имя, username) используются для обратной связи и отправки запрошенных материалов
  • Данные не продаются и не передаются третьим лицам
  • Данные не используются для автоматического профилирования

3. Файлы cookie

Сайт не использует файлы cookie, пиксели отслеживания, счётчики или рекламные скрипты. Никакие данные не сохраняются в браузере пользователя.

4. Хостинг и инфраструктура

Сайт размещён на GitHub Pages (GitHub, Inc., США). GitHub может собирать технические данные в соответствии со своей политикой конфиденциальности: docs.github.com

Чат-бот работает через платформу Telegram. При переходе в бот применяется политика конфиденциальности Telegram: telegram.org/privacy

5. Права пользователя

В соответствии с применимым законодательством (включая GDPR для пользователей из ЕС) вы вправе:

  • Запросить информацию о хранящихся данных
  • Потребовать удаления данных
  • Отозвать согласие на обработку данных
  • Подать жалобу в надзорный орган по защите данных

6. Хранение данных

Переписка в Telegram хранится до момента вашего запроса об удалении или блокировки бота. Серверные логи GitHub Pages хранятся согласно политике GitHub (как правило, не более 30 дней).

7. Изменения политики

Мы оставляем за собой право обновлять данную политику. При существенных изменениях дата обновления в заголовке будет изменена. Продолжение использования сайта означает согласие с актуальной версией политики.
